# Legacy material (2023)

This folder contains the original Jupyter notebook version of the workshop, as used at the [International Summer School of SFB/TRR 339](https://www.sfbtrr339.de/en/events/international-summer-school-of-sfb-trr-339) in August 2023:

| File | Content |
| --- | --- |
| `Task.ipynb` | The task notebook handed out to participants |
| `SampleSolution.ipynb`, `SampleSolution.html` | The sample solution, as notebook and as HTML export |
| `utilities.py` | Plotting helpers used by the notebooks |
| `Code.zip` | The original archive as distributed in 2023 |
